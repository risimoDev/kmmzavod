# Autox.js сценарии — калибровка на реальных телефонах

Эти скрипты — **отправная точка**, не готовое решение. UI-автоматизация
завязана на конкретную версию приложения/лейаут экрана и требует прогона
на настоящем телефоне из фермы, руками, с логами AutoX.js рядом (её лог
показывает, какой `text()`/`id()` селектор не находится).

Плейсхолдеры, которые `device-agent` подставляет перед отправкой в Laixi
(`ExecuteAutoJs` принимает только путь к файлу на диске ПК — подстановка
делается через генерацию временной копии скрипта с уже заполненными
значениями, см. `src/publish.ts`):

- `__VIDEO_PATH__` — путь к видео на устройстве (после `httpdown`).
- `__CAPTION__` — подпись поста (JSON-экранированная строка).

## Как калибровать

1. Откройте инстаграм/тикток на одном тестовом телефоне вручную, пройдите
   флоу создания поста, запишите **что вы нажали** (галерея → выбор видео →
   next → next → подпись → поделиться).
2. Через Laixi UI (или `screenshot`/`Current Activity` из API) сверяйте
   activity/id на каждом шаге.
3. Замените `text()`/`id()`/`desc()` селекторы ниже реальными — они сейчас
   лучшие догадки по типовым Instagram/TikTok layout, но приложения меняют
   разметку между версиями.
4. Проверяйте через `ExecuteAutoJs` на ОДНОМ устройстве, прежде чем катить
   на всю ферму.
