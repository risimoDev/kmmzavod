# Руководство: Подключение стойки из 20 плат к серверу AWS через защищенный туннель AmneziaWG

Данная инструкция описывает процесс объединения вашего сервера (AWS EC2 / Ubuntu), на котором развернут `kmmzavod`, и домашнего ПК (Windows), к которому через USB подключена 20-платная стойка телефонов под управлением встроенного Native ADB моста.

---

## 1. Архитектура соединения

```
┌───────────────────────── AWS EC2 (Ubuntu) ──────────────────────────┐
│  kmmzavod Web, API, Orchestrator (BullMQ Workers)                   │
│  AmneziaWG Server (туннельный IP: 10.13.13.1)                       │
│  Публичный IP AWS: 54.x.x.x (порт 51820/UDP)                        │
└──────────────────────────────────┬───────────────────────────────────┘
                                   │
                   Шифрованный обфусцированный туннель
                   (AmneziaWG — защита от блокировок DPI)
                                   │
┌──────────────────────────────────┴───────────────────────────────────┐
│  Домашний ПК (Windows 10/11)                                         │
│  AmneziaWG Windows Client (туннельный IP: 10.13.13.2)                │
│  apps/device-agent (слушает 10.13.13.2:8300)                         │
│  Google Android ADB Server (127.0.0.1:5037)                          │
│  USB-хаб стойки ─── 20 материнских плат Android                      │
└──────────────────────────────────────────────────────────────────────┘
```

> **Безопасность:** Домашний ПК не открывает никаких портов в публичный интернет. Общение идет строго внутри изолированной подсети `10.13.13.0/24`.

---

## 2. Настройка на сервере AWS EC2

### Шаг 2.1. Открытие порта в AWS Security Group
1. Перейдите в AWS Management Console → **EC2** → **Security Groups**.
2. Выберите Security Group вашего инстанса.
3. В **Inbound rules** добавьте правило:
   - **Type:** Custom UDP
   - **Port range:** `51820` (или ваш выбранный порт)
   - **Source:** `0.0.0.0/0` (Anywhere IPv4)
4. Сохраните правила (**Save rules**).

### Шаг 2.2. Установка AmneziaWG на сервере
Подключитесь к серверу по SSH и выполните установку:

```bash
# Скачивание и запуск официального установщика
curl -fsSL https://raw.githubusercontent.com/wiresock/amneziawg-install/main/amneziawg-install.sh -o awg-install.sh
sudo bash awg-install.sh
```

В процессе установки скрипт сгенерирует уникальные параметры обфускации:
- `Jc`, `Jmin`, `Jmax` (мусорные пакеты)
- `S1`, `S2` (размеры заголовков)
- `H1`, `H2`, `H3`, `H4` (хэши сигнатур)
- Приватный и публичный ключи сервера

### Шаг 2.3. Конфигурация сервера `/etc/amnezia/amneziawg/awg0.conf`
Убедитесь, что в файле настроен интерфейс и пир для домашнего ПК:

```ini
[Interface]
Address = 10.13.13.1/24
ListenPort = 51820
PrivateKey = <Серверный_PrivateKey>
Jc = <ваше_значение>
Jmin = <ваше_значение>
Jmax = <ваше_значение>
S1 = <ваше_значение>
S2 = <ваше_значение>
H1 = <ваше_значение>
H2 = <ваше_значение>
H3 = <ваше_значение>
H4 = <ваше_значение>

[Peer]
# Домашний ПК с фермой
PublicKey = <Публичный_ключ_клиента_Windows>
AllowedIPs = 10.13.13.2/32
```

Запустите и включите автозапуск:
```bash
sudo systemctl enable --now awg-quick@awg0
sudo systemctl status awg-quick@awg0
```

## 3. Настройка на домашнем ПК (Windows)

### Шаг 3.1. Установка клиента AmneziaWG
1. Скачайте и установите клиент для Windows:
   [AmneziaWG Windows Client Releases](https://github.com/amnezia-vpn/amneziawg-windows-client/releases)
2. Откройте приложение, нажмите **Add Tunnel** → **Add empty tunnel**.
3. Заполните конфигурацию:

```ini
[Interface]
PrivateKey = <Клиентский_PrivateKey>
Address = 10.13.13.2/32
DNS = 1.1.1.1
Jc = <ТОЧНО_ТАКИЕ_ЖЕ_КАК_НА_СЕРВЕРЕ>
Jmin = <ТОЧНО_ТАКИЕ_ЖЕ_КАК_НА_СЕРВЕРЕ>
Jmax = <ТОЧНО_ТАКИЕ_ЖЕ_КАК_НА_СЕРВЕРЕ>
S1 = <ТОЧНО_ТАКИЕ_ЖЕ_КАК_НА_СЕРВЕРЕ>
S2 = <ТОЧНО_ТАКИЕ_ЖЕ_КАК_НА_СЕРВЕРЕ>
H1 = <ТОЧНО_ТАКИЕ_ЖЕ_КАК_НА_СЕРВЕРЕ>
H2 = <ТОЧНО_ТАКИЕ_ЖЕ_КАК_НА_СЕРВЕРЕ>
H3 = <ТОЧНО_ТАКИЕ_ЖЕ_КАК_НА_СЕРВЕРЕ>
H4 = <ТОЧНО_ТАКИЕ_ЖЕ_КАК_НА_СЕРВЕРЕ>

[Peer]
PublicKey = <Серверный_PublicKey>
Endpoint = <ПУБЛИЧНЫЙ_IP_СЕРВЕРА_AWS>:51820
AllowedIPs = 10.13.13.1/32
PersistentKeepalive = 25
```

4. Нажмите **Activate**.
5. Проверьте пинг в PowerShell:
   ```powershell
   ping 10.13.13.1
   ```
   Если пинг проходит успешно — зашифрованный туннель работает!

---

## 4. Запуск моста фермы (device-agent)

1. Откройте папку проекта на домашнем ПК: `apps/device-agent`.
2. Создайте или проверьте файл `.env`:
   ```ini
   DEVICE_AGENT_HOST=10.13.13.2
   DEVICE_AGENT_PORT=8300
   ADB_PATH=adb
   DEVICE_AGENT_DOWNLOAD_DIR=/sdcard/DCIM/Camera
   ```
3. Запустите ферму двойным кликом по:
   ```
   apps/device-agent/start-farm.bat
   ```
4. В консоли отобразится список подключенных плат через ADB и сообщение о готовности:
   ```
   [OK] Интерфейс AmneziaWG активен (10.13.13.2).
   device-agent: listening on 10.13.13.2:8300
   ```

## 5. Проверка работы через Веб-интерфейс сайта

1. Перейдите на сайте в раздел **Account Farm** (`/farm`).
2. Откройте вкладку **«Стойка плат (20 шт)»**.
3. Вы увидите 20 плат стойки:
   - Зеленые индикаторы **Онлайн 🟢**.
   - Нажмите **🔍 Тест IP** на любой плате — система опросит реальный IP платы.
   - Если плата работает без прокси, отобразится защита: `⚠️ УТЕЧКА: IP совпадает с домашним!`.
   - Нажмите **🌐 Прокси** и выберите прокси из списка — плата автоматически переключится на него через ADB.
   - Нажмите **👁 Smart View** — выберите соцсеть (Instagram/TikTok), укажите `@username` и нажмите **Запустить просмотр**. Плата откроет приложение, посмотрит видео, поставит лайк и проскроллит ленту.
   - Нажмите **🛍️ Прогрев WB** — введите артикул карточки товара (SKU) на Wildberries. Плата откроет официальное приложение Wildberries по deep-link, пролистает фотогалерею, перейдет в отзывы, добавит товар в избранное (сердечко) и удержит органическое время на карточке для поднятия позиций в поиске WB.
