# Интеграция реальной телефонной фермы (Native ADB) — архитектура

## Зачем

Приватная публикация (`authMethod=private`) идёт через `apps/publisher` (instagrapi / tiktok-uploader) — эмуляция клиента без физического устройства.
У пользователя есть стойка из 20 плат Android-телефонов, подключённая по USB к домашнему ПК.
Платный проприетарный софт (Laixi Master) **полностью исключен** из архитектуры. Вместо него используется **собственный легковесный контроллер Native ADB** (`apps/device-agent/src/adb-client.ts`), работающий напрямую с официальным Google Android Debug Bridge (`platform-tools`).

Физический Android с официальным приложением Instagram/TikTok/Wildberries на чистом мобильном прокси имеет максимальный траст и практически нулевой риск детекта бот-активности.

Добавлен метод публикации и управления `authMethod=device`, который обращается к конкретной плате стойки через `apps/device-agent`.

## Топология

```
┌────────────────────── Сервер (VPS, Linux / AWS) ─────────────────┐
│  nginx / api / web / postgres / redis / minio                    │
│  orchestrator (BullMQ workers)                                   │
│    └─ publish.worker: authMethod=device → deviceAgentClient      │
│                              │ HTTP POST /publish                │
│                              │ (10.13.13.1 ← AmneziaWG →10.13.13.2)│
│  amneziawg (обфусцированный WireGuard туннель)                   │
└────────────────────────────┬──────────────────────────────────────┘
                             │ AmneziaWG туннель (UDP, обфускация трафика)
┌────────────────────────────┴──────────────────────────────────────┐
│  Домашний ПК (Windows) — куда физически подключены платы стойки   │
│  amneziawg-client (интерфейс 10.13.13.2)                          │
│  apps/device-agent (Node.js Fastify, слушает 10.13.13.2:8300)     │
│    ├─ Native AdbClient (adb.exe, Google Platform-Tools)           │
│    ├─ USB push видеофайла на плату (/sdcard/DCIM/Camera)          │
│    ├─ MediaScanner broadcast для моментальной индексации          │
│    ├─ Smart View Warmup (досмотры, лайки, скролл в IG / TikTok)   │
│    ├─ WB Warmup (прогрев карточек Wildberries, отзывы, избранное) │
│    └─ Auto-Heal (мониторинг температуры DC-DC, сброс ANR-окон)    │
│  USB 3.0 Хаб ─── 20 материнских плат Android                      │
└──────────────────────────────────────────────────────────────────┘
```

**Безопасность:** Порты не открываются в интернет. Управление идет строго внутри шифрованного обфусцированного туннеля AmneziaWG.

## Компоненты системы

1. **`infra/amneziawg/`** — конфигурация WireGuard с параметрами обфускации трафика (`Jc`, `Jmin`, `Jmax`, `S1`, `S2`, `H1-H4`) для обхода DPI-блокировок.
2. **`apps/device-agent`** — контроллер на Windows-ПК:
   - `src/adb-client.ts`: прямое выполнение команд ADB, стриминг скриншотов из памяти (`exec-out screencap -p`), эмуляция человеческих касаний и свайпов.
   - `src/wb-warmup.ts`: прогрев карточек Wildberries через deep-link `wildberries://card?nmId=...` с органическим удержанием времени, скроллом характеристик, чтением отзывов и добавлением в избранное.
   - `src/view-target.ts`: Smart View прогрев целевых аккаунтов в TikTok и Instagram Reels.
   - `src/publish.ts`: передача медиафайлов по USB и отправка интентов.
   - `src/proxy-manager.ts`: привязка и переключение мобильных прокси с pre-flight защитой от утечек (Anti-Leak test).
   - `src/auto-heal.ts`: диагностика питания, температуры, оперативной памяти и сброс зависаний.
3. **`apps/api`** — REST API бэкенда:
   - Маршруты управления фермой (`account-farm.routes.ts`).
   - Эндпоинт `/devices/:deviceId/wb-warmup` для запуска прогрева WB.
   - Синхронизация статусов плат и привязка аккаунтов соцсетей к платам (`SocialAccount.deviceId`).
4. **`apps/web`** — Веб-интерфейс (`/farm`):
   - Мониторинг всех плат в реальном времени.
   - Живой предпросмотр экрана плат по одному клику.
   - Модальное окно прогрева карточек Wildberries (артикул SKU, время задержки, свайпы фото, чтение отзывов, добавление в избранное).
   - Инструменты диагностики и авто-стабилизации.
   - Переключение мобильных прокси и проверка утечек IP.
